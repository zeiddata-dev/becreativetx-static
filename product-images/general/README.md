# Other work — for the gallery

Images here go into the general **/gallery/** page (the filterable grid of all
work), not the four case-study overlays. Use this for anything not tied to
Unitron, Momentum, Allen, or Box Insurance.

## Drop each image into its product type

```
general/
  print/      commercial printing
  promo/      promotional products
  apparel/    branded apparel
  design/     design and identity
```

The folder decides the filter the piece shows under on the gallery page. That
is the one choice that has to be right.

Name each file for what it shows, e.g. `trade-show banner.jpg`. Any of `.jpg`,
`.jpeg`, `.png`, `.webp` is fine; large files get compressed automatically.

## Notes

- The four case-study clients do **not** need re-uploading here. Their products
  already flow into the gallery from their own folders — this folder is only
  for everything else.
- No stock or borrowed art. Only real be creative work.
